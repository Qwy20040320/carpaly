# 吉利星越 L（KX11）试验性适配

当前 `v1.1.51` 为尚未交付的目标版本（`versionCode=39`）；它必须使用 Release variant、固定 v1.1.4 签名身份及 `CarPaly-XingyueL-v1.1.51.apk` 命名。`v1.1.4` 与旧格式 `v1.1.5` 均有公开预发布记录；历史文件保持不变。profile、窗口参数和自动化测试只证明软件侧存在对应配置，不证明任何年款已经实车兼容。用户对 v1.1.4 的单车连接/音乐反馈未被维护者独立复现；导航语音无声、顶部状态栏遮挡仍待回归。

此适配针对运行银河 OS 的星越 L 中控 CarPlay 接收端。它只配置 DiPlay 自己的 Android
窗口和向 iPhone 声明的 CarPlay 显示能力；不会调用车辆 CAN、空调、仪表盘、HUD 或任何未公开
的吉利/亿咖通接口。

## 已配置的内容

- 中控画布按实际窗口协商，并在诊断日志中校验 **1920 × 720**；不会把其他大小的窗口伪造成该
  分辨率。
- 对应 12.3 英寸中控屏使用 300 mm 的物理宽度，令 CarPlay 的图标和文字尺度符合实际屏幕。
- 使用全屏、H.264 和 60 fps；H.264 避免把不确定的 HEVC 解码能力带入首次连接。
- 以 `Geely / Xingyue L / GEELY` 向 CarPlay 标识接收端，便于在 iPhone 的车辆列表辨识。

星越 L 的公开参数列出 1920 × 720 中控屏、12.3 英寸屏幕和银河 OS；实际车型、地区与 OTA
版本可能不同。参考：[吉利 2025 星越 L 参数表](https://www.geely.com/-/media/project/web-portal/parallel-car/xingyuel-01/geely-xingyue-l-dongfangyao-specification-table.pdf)。

## 使用方式

1. 安装 APK 后，打开 **设置 → 车辆 → CarPlay 控制 → 车机配置**。
2. 若系统版本无法自动识别，手动选择 **吉利星越 L / KX11**。
3. 重新连接 CarPlay。首次建议使用 H.264 有线连接，确认画面、触摸、音乐和电话均正常后，再测试
   无线连接。
4. 在“保存诊断报告”中确认日志包含 `Geely Xingyue L profile`。其中 `matched=true` 表示 DiPlay
   实际获得的主窗口正是 1920 × 720；`false` 表示系统以兼容窗口、分屏或不同车型屏幕启动，仍会使用
   实际窗口以避免拉伸。

## 范围与验证

该配置不宣称支持仪表投屏、方向盘私有按键、空调联动、车辆数据、泊车状态或车辆控制。以上功能需要
按具体固件取得可验证的公开接口或实车抓取结果，不能从车型名称推断。2026 款等使用不同座舱系统或
不同屏幕规格的车型，应先选择“通用 Android 车机”并导出诊断报告。

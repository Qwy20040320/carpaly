# 星越 L 实车验收计划（驻车）

所有测试由车主在安全驻车、驻车制动和不会干扰驾驶的状态执行。OEM/HUD/车辆读数未验证前不打开任何实验写入功能，不发送 CAN、UDS、VHAL 写命令。每项记录 APK 版本/签名指纹、车型年款/配置、车机 Android/固件、CarPlay 有线/无线方式和结果；日志分享前由车主脱敏。

## 测试顺序

1. **安装升级**：先确认车内已有包名与签名指纹；对当前目标 Release APK 核对相同包名、versionCode 更高和固定 Release 证书。安装覆盖，验证设置保留；失败立即停止，不卸载旧版、不清数据。
2. **启动/页面**：启动、打开车型与连接设置；检查屏幕旋转、OEM 顶/侧系统栏、黑边/裁切、触摸位置。断开 CarPlay 不影响原车菜单与倒车画面。
3. **有线连接**：iPhone 授权后连接，记录 USB permission、iAP2/NCM 阶段、认证结果、视频 Surface 首帧、触控和断开重连；认证失败就保留日志并终止本轮，不循环拔插。
4. **无线连接**：检查 BT 发现/配对、Wi-Fi 交接、网络链路/CarPlay session 阶段、画面与重连。BT 配对或连 Wi-Fi 单独通过不能记作 CarPlay 连接通过。
5. **音频**：分别播放音乐、地图逐字导航提示、Siri、电话双向语音；观察导航期间媒体 duck/mute 后恢复；可选在驾驶员授权情况下测试麦克风。同步导出 CarPaly 诊断及驻车 ADB audio_flinger/audio_policy/media_session 只读采集。
6. **显示/生命周期**：顶部栏可见时确认安全区与触摸矩形一致；系统栏隐藏/重新显示、前后台、屏幕锁屏唤醒、Wi-Fi 中断后恢复。
7. **车辆能力**：仅先读取服务/permission/display 存在性；原厂 HUD、DIM、方向盘、燃油/转速/挡位接口仍不主动调用。若服务由官方 SDK 明确授权，再单独审核其契约与回退。

## 结果分类

每条只用 `PASS`（实际验证）、`FAIL`（实际执行失败）、`BLOCKED`（设备/权限限制）、`NOT_TESTED`。实车 CarPlay 只有真实 iPhone 完成协议认证/握手、出现可操作界面且存在日志才能记 `PASS`。HUD、仪表、OneOS、ECARX 或实车音频路径不以应用代码、模拟器、静态 APK 字符串替代验收。

| 项目 | 当前状态 |
|---|---|
| APK 安装与覆盖升级 | 等待安装本轮固定签名 Release 包；本轮未执行实车安装 |
| 有线 / 无线 CarPlay | `NOT_TESTED`（本轮不连接真实 iPhone） |
| 音乐 / 导航 / Siri / 通话 / 麦克风 | `NOT_TESTED`（包含已知导航无声问题待复测） |
| OEM 状态栏 / 触控安全区 | `NOT_TESTED` |
| 方向盘 / HUD / DIM / 燃油 / 倒车优先级 | `NOT_TESTED`；没有足够权限/接口证据时不要启用 |

发现问题请提供版本、签名是否匹配、复现步骤、期望/实际结果、脱敏诊断 ZIP 和用户明确允许的设备信息。
